Speeding up Archlinux Upgrade

Why your firmware downloads crawl while everything else flies, and how to fix it.

We've all been there. You run pacman -Syu and watch happily as small packages download instantly. Then, the process hits linux-firmware or linux-firmware-intel, and suddenly your speed drops to 50KB/s.

This is a common frustration, specifically for users in regions like Indonesia where international routing can be inconsistent. You might suspect your DNS is acting up, but the reality is usually simpler—and easier to fix.

Why is it only the firmware?

It’s not your DNS. If the download starts at all, your DNS has already done its job. The issue is likely the mirror you are connected to.

Firmware packages are "binary blobs"—large, monolithic files (often 150MB+). While a slow mirror might deliver a 1MB utility file fast enough that you don't notice the lag, a massive firmware file exposes every bottleneck in the connection. If you're pulling from a mirror with poor peering to your ISP, that specific file will crawl.

The Solution

Here is the reliable, three-step method to fix slow downloads and optimize your Arch mirror list.

1. Install Dependencies

We will use a tool called Reflector to find the fastest mirrors. It requires rsync to accurately test download speeds.

sudo pacman -S rsync reflector

2. Update Your Mirrorlist

If you are in Indonesia, relying solely on local mirrors can sometimes be unstable for large files. The pro-tip is to include Singapore mirrors, which often have better bandwidth and reliability.

sudo reflector --country Indonesia,Singapore --latest 20 --sort rate --save /etc/pacman.d/mirrorlist

3. Enable Parallel Downloads

This is the game changer. By default, Pacman downloads one file at a time. If that one file (like firmware) is slow, the whole update stops. Enabling parallel downloads lets Pacman grab 5 files at once.

# Open /etc/pacman.conf and uncomment:
ParallelDownloads = 5

Once you've applied these changes, run sudo pacman -Syu again. You should see a significant improvement in speed, and the dreaded firmware stall should be a thing of the past.
